# 🧮 수라당 수량 계산기

수라당의 떡 생산을 위한 전문 웹 애플리케이션입니다. 파란상자 배분을 최적화하여 효율적인 포장과 적재를 도와줍니다.

## ✨ 주요 기능

### 🎯 스마트 계산
- **총 떡 수량 입력**: 생산된 전체 떡 개수를 입력
- **상자당 개수 설정**: 파란상자에 넣을 떡의 개수 지정 (예: 64, 90, 100개)
- **줄당 상자 범위**: 한 줄에 쌓을 상자 개수를 20~23개 범위에서 자동 최적화
- **실시간 계산**: 입력과 동시에 최적의 배치 계산

### 📊 상세 결과 표시
- 총 필요 상자 개수
- 최적 줄 수
- 줄당 상자 개수
- 마지막 줄 상자 개수
- 남은 떡 개수 및 추가 필요 수량

### 🎨 시각화
- 직관적인 상자 배치 시각화
- 줄별 상세 정보 표시
- 반응형 디자인으로 모든 화면 크기 지원

## 💡 사용 예시

### 예시 1: 12,000개 생산
```
입력:
- 총 떡 수량: 12,000개
- 파란상자 당: 100개
- 한 줄당: 20~23개

결과:
- 총 상자: 120개
- 배치: 20개씩 6줄
- 마지막 줄: 20개 (완전 배치)
```

### 예시 2: 11,000개 생산
```
입력:
- 총 떡 수량: 11,000개
- 파란상자 당: 100개
- 한 줄당: 20~23개

결과:
- 총 상자: 110개
- 배치: 22개씩 5줄
- 마지막 줄: 10개
```

## 🚀 사용 방법

### 웹 브라우저에서 사용

1. **로컬 서버 실행** (간단한 방법)
   ```bash
   # Python이 설치되어 있다면:
   python3 -m http.server 8000

   # 또는 Node.js가 있다면:
   npx serve
   ```

2. **브라우저에서 접속**
   ```
   http://localhost:8000
   ```

3. **입력 필드 작성**
   - 총 떡 수량 입력
   - 파란상자당 떡 개수 입력
   - 필요시 줄당 상자 개수 범위 조정 (기본값: 20~23)

4. **계산하기 버튼 클릭**

5. **결과 확인**
   - 요약 통계 확인
   - 상세 배치 정보 확인
   - 시각화로 배치 패턴 확인

### 📱 모바일에서 사용

1. **홈 화면에 추가** (PWA 기능)
   - iOS: Safari에서 열기 → 공유 → 홈 화면에 추가
   - Android: Chrome에서 열기 → 메뉴 → 홈 화면에 추가

2. **앱처럼 사용**
   - 설치 없이 웹앱으로 동작
   - 오프라인 지원 (추후 업데이트)

## 🛠 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **UI Framework**: Tailwind CSS
- **디자인**: 2025년 최신 트렌드 적용
  - 그라디언트 배경
  - 글래스모피즘 효과
  - 부드러운 애니메이션
  - 반응형 레이아웃

## 🎨 디자인 특징

### 모던 UI/UX
- **글래스모피즘**: 반투명 유리 효과로 세련된 느낌
- **그라디언트**: 보라-파랑 그라디언트 배경
- **애니메이션**: 부드러운 페이드인, 슬라이드업 효과
- **반응형**: 모바일부터 데스크톱까지 완벽 대응

### 사용자 경험
- **직관적 입력**: 큰 입력 필드, 명확한 레이블
- **실시간 피드백**: 입력 검증 및 오류 메시지
- **햅틱 피드백**: 모바일 진동 지원
- **로컬 저장**: 입력값 자동 저장/복원

## 📐 계산 로직

### 최적화 알고리즘
1. 총 상자 개수 계산: `총 떡 개수 ÷ 상자당 개수`
2. 설정된 범위(20~23) 내에서 최적 배치 찾기
3. 우선순위:
   - 나머지 없이 완전 배치 (최우선)
   - 마지막 줄도 설정 범위 내 (차선)
   - 마지막 줄을 최대한 채움 (차차선)
4. 같은 조건이면 총 줄 수가 적은 것 선택

### 특수 케이스 처리
- 남은 떡이 있을 경우 알림 표시
- 추가 필요 수량 안내
- 입력값 검증 및 오류 처리
